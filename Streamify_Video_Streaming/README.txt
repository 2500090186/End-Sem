STREAMIFY - VIDEO STREAMING FRONTEND
=====================================

Technology:
- HTML
- CSS
- JavaScript

How to run:
1. Extract this ZIP.
2. Open the "Streamify_Video_Streaming" folder in VS Code.
3. Open index.html in a browser.
4. Recommended: install the "Live Server" VS Code extension and right-click
   index.html -> "Open with Live Server".

Features:
- Mood-based video discovery
- Search
- Video cards
- Demo video player modal
- Favorites saved in browser localStorage
- Responsive design
- Home, Videos and About sections

Important:
This is a frontend prototype. The videos are represented by demo cards, so
no backend, database, login, payment system, or real streaming server is required.

PROJECT EXPLANATION:
"Our project is a mood-based video streaming frontend called Streamify.
Users can search videos, choose a mood, browse recommended content, watch a
demo player, and save favorites. HTML provides the structure, CSS handles
the design, and JavaScript provides filtering, search, favorites and the
video-player interaction."

Unique Feature:
Mood-based video selection. Instead of only browsing by category, users can
select Happy, Energetic, Relaxed, Romantic or Thriller and get matching videos.
